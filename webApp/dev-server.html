Build Instructions

  1. Ensure you have stable internet connection
  2. Run the compilation command:
    ./gradlew wasmJsBrowserProductionWebpack
  3. Compiled files will be in:
    webApp/build/dist/wasmJs/productionWebpack/
  4. Open index.html in your browser to play!
